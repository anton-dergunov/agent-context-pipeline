Info Triage Capture

Extension settings

Server

Where your Info Triage server is, and the token it expects.

The address the dashboard opens at, for example http://192.168.1.10:8000 or https://my-server.my-tailnet.ts.net:8443.
The value of INFO_TRIAGE_CAPTURE_TOKEN in the server's .env.

Routes

The routes come from the server's configuration. Test the connection to load them.

Keyboard Shortcut

Trigger text & URL capture using a key combination without clicking the toolbar icon.

Default Key Combo: Command + Shift + K (Mac) / Ctrl + Shift + K (Win)

To customize or change this shortcut, open Chrome's native shortcuts manager at chrome://extensions/shortcuts.
