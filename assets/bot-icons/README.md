# Bot icons

Profile pictures for the Telegram bots, one per route. At the size of a share sheet a distinct
picture tells the bots apart faster than a name does. Each comes plain and with a border
(`-borders`), the bordered one being easier to pick out on a dark background.

| File | Suggested route |
|---|---|
| `book.png` | `info` — things to read and think about |
| `businessman.png` | `job` — job postings |
| `video.png` | `clip` — video clips |
| `languages.png` | a vocabulary route, if you add one |

`book.png` is also the browser extension's icon.
